# Student Habits and Academic Performance Analysis 📊

This repository contains a data science group project completed for the **Fundamentals of Data Science and Data Analytics** course. The project investigates how daily habits—such as study hours, digital entertainment consumption, and sleep—affect final exam scores.

## 📁 Files Included
* **`Group5.ipynb`**: The Jupyter Notebook containing the Python code for data cleaning, exploratory data analysis (EDA), correlation matrices, and statistical validation.
* **`Students_Habits_and_Performance_Analysis.docx`**: The comprehensive final report detailing our methodology, visual observations, and analytical interpretations.

## 🛠️ Tools & Technologies Used
* **Languages:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, SciPy
* **Environment:** VS Code, Jupyter Notebook

## 📈 Key Insights
Based on our analysis of the dataset, we concluded the following:
* **The "Study Threshold":** Students who studied more than 3.5 hours per day averaged a final exam score of 80.10, while those studying less averaged 57.81.
* **The Displacement Effect:** Time spent on Netflix (r = -0.172) and social media (r = -0.167) showed the strongest negative correlations with exam scores, actively cannibalizing study and sleep time.
* **Statistical Certainty:** An independent samples T-Test resulted in a p-value of 8.47e-126, proving with near-absolute certainty that the performance advantage of the high-study group is genuine.
